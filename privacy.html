Политика конфиденциальности

Эта политика относится к служебному OAuth-приложению Tracker GitHub TEST Access, используемому владельцем проекта для чтения исходного кода Google Apps Script.

Какие данные доступны приложению

После отдельного разрешения владельца Google предоставляет приложению доступ https://www.googleapis.com/auth/script.projects.readonly. Он позволяет получить содержимое проектов Apps Script, к которым пользователь имеет доступ: исходные файлы и манифест. Это разрешение не позволяет изменять проекты.

Зачем используются данные

Только для получения резервной копии исходников, проверки версий и диагностики программного кода в интересах владельца. В текущем режиме одноразовый инструмент читает выбранный тестовый проект и сохраняет результат локально на компьютере владельца.

Хранение и передача

В текущей версии одноразовый инструмент не сохраняет OAuth-токены. Локальная копия исходников остаётся на устройстве владельца и не публикуется на этом сайте. Мы не продаём полученные через Google данные и не используем их для рекламы. Отдельная будущая интеграция с GitHub Actions, если будет включена, потребует обновления этой политики до начала передачи или хранения дополнительных данных.

Посещение сайта

Этот сайт не содержит форм регистрации, рекламных счётчиков и аналитических скриптов. Он размещается на GitHub Pages; поставщик хостинга может обрабатывать технические данные посещения, включая IP-адрес, в соответствии со своей политикой конфиденциальности.

Контроль пользователя

Владелец может отозвать доступ приложения в настройках подключений Google и удалить локальные резервные копии со своего компьютера. Для вопросов о проекте используйте профиль владельца на GitHub либо контактный адрес, указанный на экране согласия Google.

English summary.

This private developer tool requests only script.projects.readonly to read source files and manifests from Google Apps Script projects accessible to the authorizing user. Current one-time backups are kept on the owner's device; OAuth tokens are not persisted by that helper. No Google user data is sold or used for advertising. This informational GitHub Pages site does not receive OAuth tokens. The owner can revoke access in Google Account settings.
