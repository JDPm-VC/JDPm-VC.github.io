Политика конфиденциальности

Эта политика относится к служебному OAuth-приложению Tracker GitHub TEST Access, используемому владельцем для чтения исходного кода Google Apps Script. Общедоступной регистрации нет. Подготовка облачного режима сама по себе не включает его: требуется отдельное согласие и настройка доступа владельцем.

Данные и разрешение

Приложение запрашивает только https://www.googleapis.com/auth/script.projects.readonly: исходные файлы и манифест проектов Apps Script, доступных авторизующемуся аккаунту. Это разрешение не позволяет изменять проекты. Подготовленный код обращается только к выбранному тестовому проекту; ограничение одного проекта выполнено в программе, а не в самом OAuth-разрешении Google. Исходники могут содержать данные или секреты, которые владелец ранее включил в код.

Для чего используются данные

Для резервирования и технической сверки версий в интересах владельца. Данные Google не продаются, не используются для рекламы или обучения моделей общего назначения. В режиме облачной сверки программа не запускает функции Apps Script и не запрашивает доступ к Google Drive или Google Sheets.

Два отдельных режима

Разовое локальное чтение. Программа первого чтения сохраняет резерв исходников на компьютере владельца. Полученные OAuth-токены ею не сохраняются. Этот режим не подключает GitHub к Google постоянно.

Облачное чтение после отдельного разрешения. Владелец может предоставить длительный доступ с тем же readonly-разрешением и сохранить данные клиента и токен продления в отдельных GitHub Actions Secrets приватного репозитория. Тогда GitHub выступает поставщиком обработки и хранения этих данных. Облачная программа получает исходники из Google в память временного исполнителя GitHub, вычисляет контрольные суммы и не записывает исходный код в журнал, репозиторий или скачиваемый артефакт.

В закрытом отчёте GitHub сохраняются только время проверки, число файлов, контрольные суммы и результат сравнения. Эти технические сведения могут читаться владельцем и его разрешёнными инструментами сопровождения, в том числе подключением GitHub в ChatGPT. Через этот отчёт исходники и токены в ChatGPT не передаются. Настройка облачного чтения не является автоматическим включением расписания.

Хранение, доступ и удаление

Локальные резервы хранятся до удаления владельцем. GitHub Secrets хранятся до удаления или замены владельцем; журналы и технические отчёты — в соответствии с настройками хранения GitHub. Пользователи с правом изменения сценариев репозитория потенциально могут использовать выданные полномочия: доступ к приватному репозиторию следует предоставлять только доверенным лицам.

Остановить дальнейший доступ можно отзывом разрешения в настройках подключений Google. Для удаления сохранённых данных отдельно удалите соответствующие GitHub Secrets, журналы запусков и локальные резервы. Удаление секрета в GitHub само по себе не отзывает Google-разрешение. Токены могут истечь или быть отозваны; бессрочная доступность не обещается.

Информационный сайт и связь

Этот сайт не принимает OAuth-токены, не содержит форм регистрации, рекламы и аналитических скриптов. GitHub Pages может обрабатывать технические данные посещения, включая IP-адрес, согласно политике GitHub. Контакт: профиль владельца или адрес на экране согласия Google.

English summary.

This owner-operated utility requests only Apps Script project read access. The existing one-time helper keeps source backups on the owner's device and does not persist OAuth tokens. An optional, separately authorized cloud mode stores individual credentials in private GitHub Actions Secrets and processes source files in an ephemeral GitHub runner's memory. Only aggregate technical reports are retained; source and tokens are not sent to ChatGPT through those reports. No Google data is sold, used for advertising or for training general-purpose models. The public website receives no OAuth credentials. The owner controls revocation in Google and deletion of secrets, logs and local backups.
