Надёжная связь между исходным кодом и проверками.

Tracker GitHub TEST Access — служебное подключение владельца проекта «Жесткий бизнес-трекер 3». Оно предназначено для чтения исходников Google Apps Script, проверки версий и создания резервных копий. Это не общедоступный сервис для регистрации пользователей.

Доступ только на чтениеGoogle Apps ScriptПриватный тестовый проект

Что делает подключение

01 / Читает код

Получает исходные файлы Apps Script владельца с явно предоставленным разрешением Google.

02 / Помогает проверять

Позволяет сравнивать версии кода перед изменениями и находить расхождения.

03 / Создаёт резерв

В текущем тестовом режиме сохраняет копию исходников локально на компьютере владельца.

О доступе: используемое сейчас разрешение script.projects.readonly не даёт приложению права изменять или удалять проекты Apps Script. Этот информационный сайт не принимает OAuth-токены и не содержит исходников бизнес-трекера.

English summary.

Tracker GitHub TEST Access is a private developer utility for the owner of a business-tracker project. Its current Google OAuth scope is read-only access to Google Apps Script projects. The tool fetches source files for local backup and verification. This public website is informational only and does not receive OAuth tokens or business data.
