Условия использования

Tracker GitHub TEST Access — служебный инструмент для владельца и специально разрешённых тестовых пользователей. Он не является открытым коммерческим сервисом.

Назначение

Приложение используется для чтения исходных файлов Google Apps Script и технического сопровождения проекта. Пользователь предоставляет доступ через официальный экран Google OAuth и может отменить разрешение в настройках своего Google-аккаунта.

Обязанности пользователя

Используйте приложение только для проектов, к которым у вас есть законный доступ. Не передавайте OAuth-токены, пароли, секреты и содержимое чужих проектов через публичные формы, GitHub Issues или комментарии.

Доступность

Технический инструмент предоставляется для тестирования без обещаний непрерывной доступности. Изменения способов хранения или использования Google-данных должны быть отражены в политике конфиденциальности до их включения.

Связь

Связаться с владельцем можно через профиль GitHub или через контактный адрес, указанный при авторизации Google.

English summary.

This is an owner-operated developer utility for authorized testing and backup of Google Apps Script source code. There is no public account registration.
