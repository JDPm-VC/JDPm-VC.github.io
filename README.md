# Tracker GitHub TEST Access — публичная информационная страница

Сайт для Google OAuth Branding. **Не содержит** код приватного трекера, исходники Apps Script, токены и конфигурации.

Адрес при размещении в репозитории `JDPm-VC/JDPm-VC.github.io`: `https://jdpm-vc.github.io/`.

Страницы: `/`, `/privacy.html`, `/terms.html`. Все файлы — статические HTML/CSS, без JavaScript, форм и внешних аналитик.

Перед включением нового способа хранения Google-данных необходимо проверить и обновить политику конфиденциальности. До публикации проверьте публичный текст и способы связи; не добавляйте сюда секреты, личные документы или таблицы.

После создания репозитория: Settings → Pages → Deploy from a branch → `main`, `/(root)` → Save. HTTPS включить, если появится соответствующая настройка.

Для Google OAuth подтвердите владение адресом через Google Search Console (URL-prefix), например HTML-файлом в корне сайта; затем добавьте `jdpm-vc.github.io` в Authorized domains и укажите URL всех трёх страниц. Google может потребовать отдельную верификацию, успешная публикация не гарантирована.
